# Derived Agent Memory

This directory is a searchable context overlay for Vibes Dashboard agents.

- `memory-index.json` is the discovery manifest.
- `memories/codebase_insights/` contains concise semantic summaries.
- `memories/architectural_decisions/` points to accepted ADRs.
- `memories/patterns_and_lessons.md` captures reusable procedural knowledge.

Authority remains with current code/tests, accepted ADRs, `CONTEXT.md`, `HERMES.md`, and `AGENTS.md`. Memory entries must be verified through their source references before use. See [`../BOOTSTRAP.md`](../BOOTSTRAP.md) for update and safety rules.
